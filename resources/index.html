Disassemblers & Decompilers

  • Ghidra — free, open-source, scriptable
  • IDA Free — industry standard (free tier)
  • rizin / Cutter — radare2 successor
  • Binary Ninja — commercial, great API

Debuggers

  • x64dbg — free Windows debugger
  • GDB — Linux standard
  • Voltron — GDB UI upgrade
  • ScyllaHide — anti-anti-debug

PE & Static Analysis

  • pefile (Python) — PE parsing library
  • Detect It Easy — packer/compiler ID
  • CFF Explorer — PE editing suite
  • FLOSS — obfuscated string extraction

Dynamic Analysis & Sandboxes

  • REMnux — RE Linux toolkit distro
  • Cuckoo Sandbox — automated analysis
  • Sysinternals — ProcMon, etc.
  • Wireshark — packet analysis

Learning Platforms

  • TryHackMe — guided labs

  • PortSwigger Academy — web security

Programming

  • HackerRank — practice & challenges

  • HackerOne — bug bounty

Books
